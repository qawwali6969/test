### 3. Описание решения

Создайте документ с описанием (можно в README.md или отдельный файл):

#### A. Промпт(ы) для AI

**Системный промпт:**
```
См. файл prompts.py → SYSTEM_PROMPT

Ключевые элементы:
- Роль: опытный контент-маркетолог с 10+ лет опыта
- Запрещенные фразы: "в современном мире", "важно отметить" и т.д.
- Разрешенные приемы: разговорные обороты, эмоции, личный опыт
- Адаптация под нишу, цель и формат
- Контроль естественности и "человечности"
```

**Промпт для генерации идей:**
```
См. файл prompts.py → IDEAS_GENERATION_PROMPT

Требует строго 5 идей в формате:
1. [Название]
   [Описание 2-3 предложения]
```

**Промпт для генерации поста:**
```
См. файл prompts.py → POST_GENERATION_PROMPT

Требует:
- Длина 150-300 слов
- Структура: хук → суть → финал
- Естественный язык, умеренные эмодзи
```

#### Б. Логика интеграции

**Схема работы:**

```
Пользователь
    ↓
[Telegram Bot]
    ↓
Текстовое сообщение (естественный язык)
    ↓
[bot.py: handle_message()]
    ↓
Формирование промпта:
- SYSTEM_PROMPT (роль + правила)
- IDEAS_GENERATION_PROMPT (формат)
- Запрос пользователя
    ↓
[OpenAI API]
    ↓
Ответ с 5 идеями
    ↓
[Парсинг: parse_ideas()]
    ↓
Отображение кнопок
    ↓
Пользователь выбирает идею
    ↓
[bot.py: handle_idea_selection()]
    ↓
Формирование промпта для поста
    ↓
[OpenAI API]
    ↓
Готовый пост
    ↓
Отображение + кнопки действий
    ↓
[Сохранение в JSON]
```

**Модули:**

1. `bot.py` - основная логика бота (команды, обработчики)
2. `config.py` - конфигурация (API ключи, настройки)
3. `prompts.py` - все промпты для AI
4. `storage.py` - работа с историей (JSON)

**Интеграция OpenAI:**

```python
async def call_openai(system_prompt, user_prompt):
    response = openai_client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_prompt}
        ],
        temperature=0.8  # Для творческих ответов
    )
    return response.choices[0].message.content
```

#### В. Структура данных

**Контекст пользователя (в памяти бота):**
```python
context.user_data = {

    'ideas_text': str,        # Текст всех идей
```

**Структура идеи:**
