# 🤖 AI-генератор контент-идей

Telegram-бот для генерации идей контента с помощью искусственного интеллекта.

## 📋 Описание

Инструмент помогает создавателям контента генерировать идеи и готовые посты на основе трех параметров:
- **Ниша** (фитнес, бизнес, образование и т.д.)
- **Цель** (привлечь аудиторию, обучить, продать)
- **Формат** (пост в соцсетях, статья, видео)

### Основные возможности:
✅ Обработка запросов на естественном языке (без кнопок!)
✅ Генерация 5 уникальных идей с описаниями
✅ Создание готовых постов на основе выбранной идеи
✅ Сохранение избранных постов в историю
✅ Системный промпт для максимального "очеловечивания" текстов

## 🚀 Как работает

### 1. Пользователь описывает задачу
```
"Нужны идеи для фитнес-блога в Инстаграм, хочу привлечь новую аудиторию"
```

### 2. AI генерирует 5 идей
```
💡 1. 30-дневный челлендж с прогрессией
💡 2. Развенчание мифов о питании
💡 3. История трансформации подписчика
💡 4. Лайфхаки для занятых людей
💡 5. Сравнение популярных диет
```

### 3. Пользователь выбирает идею кнопкой

### 4. AI создает готовый пост
```
📝 Готовый пост:
[Живой, естественный текст 150-300 слов]
```

### 5. Действия с постом
- 💾 Сохранить в избранное
- 🔄 Выбрать другую идею
- 🆕 Новый запрос

## 📦 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone <repository-url>
cd <repository-folder>
```

### 2. Создайте виртуальное окружение
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

Заполните `.env` своими ключами:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
```

#### Где взять ключи:

**Telegram Bot Token:**
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

**OpenAI API Key:**
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в [API keys](https://platform.openai.com/api-keys)
3. Создайте новый API ключ
4. Скопируйте ключ

### 5. Запустите бота
```bash
python bot.py
```

Вы должны увидеть:
```
🤖 Бот запущен!
```

## 🧠 Системный промпт

Бот использует специально разработанный системный промпт для создания естественных, "человечных" текстов.

### Ключевые принципы промпта:

#### ❌ Запрещено:
- Фразы вроде "в современном мире", "важно отметить", "давайте рассмотрим"
- Идеальные списки и академический стиль
- Шаблонные конструкции
- Любые следы AI

#### ✅ Разрешено и рекомендуется:
- Разговорные обороты: "короче", "смотрите", "честно"
- Личный опыт: "я пробовал", "у клиента сработало"
- Эмоции: "обожаю этот приём", "ненавижу, когда так делают"
- Вопросы к читателю: "знаете, что интересно?"
- Короткие фразы и естественные паузы

### Полный текст системного промпта

См. файл `prompts.py` → переменная `SYSTEM_PROMPT`

Промпт включает:
1. **Роль и позиционирование** - опытный контент-маркетолог
2. **Правила очеловечивания** - как избегать AI-стиля
3. **Форматы генерации** - структура идей и постов
4. **Адаптация** - под нишу, цель и формат
5. **Чек-проверка** - критерии качества перед выдачей
6. **Контроль естественности** - ритм, эмоции, шероховатости
7. **Неявная адаптация** - подстройка под стиль пользователя

## 🔄 Логика работы

### Процесс генерации идей:

1. **Получение запроса** от пользователя (естественный язык)
2. **Формирование промпта**:
   - Системный промпт (роль + правила)
   - Промпт генерации идей (формат вывода)
   - Запрос пользователя
3. **Вызов OpenAI API** (GPT-3.5-turbo, temperature=0.8)
4. **Парсинг ответа** в структуру идей
5. **Отображение** с кнопками для выбора

### Процесс генерации поста:

1. **Получение выбора** идеи через callback
2. **Формирование промпта**:
   - Системный промпт
   - Промпт генерации поста
   - Исходный запрос + выбранная идея
3. **Вызов OpenAI API**
4. **Отображение** готового поста с кнопками действий

### Сохранение в историю:

- Формат: JSON
- Структура: `{user_id: [массив записей]}`
- Каждая запись содержит: timestamp, request, idea, post

## 🐛 Решение проблем

### Бот не запускается
- Проверьте наличие `.env` файла
- Убедитесь, что токены правильные
- Проверьте установку зависимостей: `pip list`

### Ошибка OpenAI API
- Проверьте баланс аккаунта OpenAI
- Убедитесь, что API ключ активен
- Проверьте rate limits

### Бот не отвечает
- Проверьте логи в консоли
- Убедитесь, что бот запущен
- Проверьте интернет-соединение
