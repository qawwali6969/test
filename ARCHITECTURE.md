## 🤖 Промпты для AI

### 1. SYSTEM_PROMPT (Базовый промпт)
**Файл:** `prompts.py:5-95`

**Назначение:** Определяет личность AI - "Каролина", контент-маркетолог с 10+ лет опыта

**Ключевые секции:**
```
0. ВСТУПЛЕНИЕ - автоматический onboarding
1. ПЕРЕД НАЧАЛОМ - уточнение формата и цели
2. ПРАВИЛА "ОЧЕЛОВЕЧИВАНИЯ" - запреты и разрешения для естественности
3. ФОРМАТЫ ГЕНЕРАЦИИ - структура идей и постов
4. АДАПТАЦИЯ - под нишу, цель, формат
5. ЧЕК-ПРОВЕРКА - контроль качества перед выдачей
6. ВСТРОЕННАЯ ЛОГИКА ЕСТЕСТВЕННОСТИ - ритм, шероховатости, эмоции
7. НЕЯВНАЯ АДАПТАЦИЯ ПОД ПОЛЬЗОВАТЕЛЯ - анализ стиля общения
8. СТИЛЬ ОБЩЕНИЯ - уверенный, короткий, без канцелярита
```

**Температура:** 0.8 для идей, 0.7 для постов

**Важно:**
- Женский род во ВСЕХ ответах ("поняла", "сделала", НЕ "понял")
- Запрещены клише типа "в современном мире", "важно отметить"
- Разрешены разговорные обороты: "короче", "смотрите", "честно"

**Файл:** `prompts.py:125-136`

**Требования:**

### NLP Parser (Умный парсер)
**Файл:** `nlp_utils.py`

**Назначение:** Извлечение параметров из свободного текста

**Функции:**
```python
smart_parse_user_request(text: str) -> dict
# Возвращает: {"niche": str, "goal": str, "format": str}

extract_missing_fields(parsed: dict) -> list
# Возвращает: список недостающих полей

looks_like_content_request(text: str) -> bool
# Проверяет, похож ли текст на запрос контента
```

**Словари:**
- **GOALS** - глаголы целей: "привлечь", "обучить", "продать", "развлечь", "набрать"
- **FORMATS** - форматы с падежами: "пост", "инста", "инсты", "телеги", "видео"
- **GOAL_SYNONYMS** - нормализация: "набрать" → "привлечь"
- **FORMAT_SYNONYMS** - нормализация: "инсты" → "instagram"

**Паттерны извлечения:**
```python
# Цель: regex поиск глаголов из GOALS
pattern = r"\b{goal}\w*"

# Формат: поиск по словарю FORMATS
pattern = r"\b{format}\b"

# Ниша: паттерны "про X", "для X", "о X"
# Важно: пропускает форматы! is_format_word()
patterns = [
    r"про\s+([а-яё0-9 \-]+?)(?:\.|,|\s+(?:чтобы|для|про)|$)",
    r"(?:для|о|по)\s+([а-яё0-9 \-]+?)(?:\.|,|$)"
]
```

**Интеграция в состояния:**

1. **В `handle_free_text()` (автостарт):**
```python
if looks_like_content_request(user_text):
    parsed = smart_parse_user_request(user_text)
    if len(extract_missing_fields(parsed)) == 0:
        # Все параметры есть - сразу генерируем!
        return generate_ideas_immediately()
```

2. **В `get_niche()` (пропуск вопросов):**
```python
parsed = smart_parse_user_request(niche)
missing = extract_missing_fields(parsed)

if len(missing) == 0:
    # Все параметры в одном ответе!
    context.user_data['niche'] = parsed['niche']
    context.user_data['goal'] = parsed['goal']
    context.user_data['format'] = parsed['format']
    return generate_ideas_immediately()

# Сохраняем ВСЕ найденные параметры
if parsed['niche']: context.user_data['niche'] = parsed['niche']
if parsed['goal']: context.user_data['goal'] = parsed['goal']
if parsed['format']: context.user_data['format'] = parsed['format']
```

3. **В `get_goal()` (пропуск формата):**
```python
parsed = smart_parse_user_request(goal)

if parsed['format'] and 'format' not in context.user_data:
    context.user_data['format'] = parsed['format']
    # Потом пропустит ASKING_FORMAT
```

### AI Валидация
**Файл:** `bot.py:validate_user_answer()`

**Назначение:** Проверка качества ответов пользователя

**Статусы:**
- `VALID` - ответ понятный, принимаем
- `UNCLEAR` - неясный ответ, просим уточнить
- `QUESTION` - пользователь задает вопрос вместо ответа
- `OFF_TOPIC` - совсем не по теме

**Промпт:**
```python
f"""Пользователь должен был указать {expected_field}.
Он написал: "{user_answer}"

Оцени ответ: VALID / UNCLEAR / QUESTION / OFF_TOPIC
Если VALID - просто подтверди. Если нет - объясни что не так."""
```

**ВАЖНО:** Валидация идет ПОСЛЕ парсера, чтобы не блокировать извлечение параметров!

### Callback Handlers (Кнопки)

**Идеи:**
- `idea_{number}` - выбор идеи
- `idea_random` - случайная идея
- `ideas_regenerate` - еще 5 идей

**Сохранение:**
- `save_yes` - сохранить пост
- `save_no` - не сохранять

**Переиспользование:**
- `reuse_yes` - генерировать с теми же параметрами
- `reuse_edit_niche` - изменить нишу
- `reuse_edit_goal` - изменить цель
- `reuse_edit_format` - изменить формат

**История:**
- `history_page_{page}` - пагинация
- `view_post_{idx}_{page}` - просмотр поста
- `delete_post_{idx}_{page}` - удаление

### Поток данных

```
1. Пользователь вводит текст
   ↓
2. handle_free_text() или state handler
   ↓
3. smart_parse_user_request() - извлечение параметров
   ↓
4. validate_user_answer() - проверка качества (AI)
   ↓
5. Сохранение в context.user_data
   ↓
6. Проверка: все параметры собраны?
   ├─ Да → Генерация идей (AI)
   └─ Нет → Следующий state
   ↓
7. Парсинг идей: parse_ideas()
   ↓
8. Показ inline кнопок для выбора
   ↓
9. Пользователь выбирает идею
   ↓
10. Генерация поста (AI)
   ↓
11. Показ с кнопками "Сохранить" / "Не сохранить"
   ↓
12. Предложение переиспользовать параметры
```

## 🗺️ Схема работы

### Сценарий 1: Полный ввод сразу (Автостарт)

```
Пользователь: "Создай пост про яблоки для инсты чтобы набрать подписчиков"
                           ↓
        handle_free_text() - любой текст вне conversation
                           ↓
        looks_like_content_request() → TRUE
                           ↓
        smart_parse_user_request()
                           ↓
        Result: {niche: "яблоки", goal: "привлечь", format: "instagram"}
                           ↓
        extract_missing_fields() → []  (все есть!)
                           ↓
        Сохраняем все параметры в context.user_data
                           ↓
        AI: Генерация 5 идей
                           ↓
        Показ inline кнопок для выбора
```

---

### Сценарий 2: Пошаговый сбор с пропуском (Умный парсер)

```
Пользователь: /start
                           ↓
Бот: "Как тебя зовут?"
                           ↓
Пользователь: "Иван"
                           ↓
        get_name() → ASKING_NICHE
                           ↓
Бот: "Какая тема?"
                           ↓
Пользователь: "Про путешествия для телеги"
                           ↓
        get_niche():
            smart_parse_user_request()
            Result: {niche: "путешествия", goal: "", format: "telegram"}
                           ↓
            Сохраняем: niche="путешествия", format="telegram"
            missing = ["goal"]  (только цели нет!)
                           ↓
Бот: "Путешествия - интересная тема! И формат тоже понял - telegram 👍
      Какая цель?"
                           ↓
Пользователь: "Набрать подписчиков"
                           ↓
        get_goal():
            validate_user_answer() → VALID
            Сохраняем: goal="Набрать подписчиков"
                           ↓
            Проверяем: format уже есть в user_data!
                           ↓
            ПРОПУСКАЕМ ASKING_FORMAT
                           ↓
        AI: Генерация 5 идей сразу!
```

## 🔑 Ключевые улучшения в текущей версии

1. **Умный NLP парсер** - извлекает все параметры из одного сообщения
2. **Автостарт** - не нужен /start, бот понимает запросы автоматически
3. **Пропуск вопросов** - если параметр уже извлечен, не спрашиваем повторно
4. **Русские падежи** - распознает "инсты", "телеги", "ютуба" и т.д.
5. **Синонимы целей** - "набрать" → "привлечь", "обучить" распознается
6. **Правильный порядок** - парсер ПЕРЕД валидацией, чтобы не блокировать извлечение
7. **Фильтрация форматов** - ниша не захватывает форматы ("про путешествия для телеги" → niche="путешествия", НЕ "телеги")
8. **Inline кнопки** - вместо текстового ввода для переиспользования параметров
9. **Random идея** - случайный выбор из 5
10. **Регенерация** - еще 5 идей с теми же параметрами

## 📊 Метрики качества

**Успешные сценарии:**
- ✅ "Создай пост про фитнес для инсты чтобы привлечь" → все параметры, 0 вопросов
- ✅ "Про яблоки для инсты" → ниша + формат, 1 вопрос (цель)
- ✅ "Набрать подписчиков для видео" (в ответ на цель) → парсит формат, пропускает вопрос

**Токены на запрос:**
- Генерация идей: ~1000-1500 tokens
- Генерация поста: ~800-1200 tokens
- Валидация: ~200-400 tokens

**Время ответа:**
- Идеи: 3-5 секунд
- Пост: 2-4 секунды
- Валидация: 1-2 секунды
